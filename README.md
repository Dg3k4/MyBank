# MyBank

Fullstack web-приложение интернет-банка.

Проект разрабатывается для практики проектирования финансовых сервисов, серверной бизнес-логики, авторизации, работы с банковскими счетами, картами и транзакциями.

> Проект находится в активной разработке.

## Возможности

На текущем этапе реализуются:

- регистрация и авторизация пользователей;
- JWT access- и refresh-токены;
- подтверждение чувствительных операций через PIN;
- банковские счета;
- основные, дополнительные и совместные карты;
- переводы между картами;
- история транзакций;
- дневные и месячные лимиты;
- статусы карт и операций;
- разграничение доступа;
- активация аккаунта по электронной почте;
- светлая и тёмная темы интерфейса.
